# Mark Step Done "[step_description]"

1. Find the current issue file in `.opencode/issues/`.
2. Locate the step matching "[step_description]" in the Progress Tracking section.
3. Change `[ ]` or `[/]` to `[x]`.
4. Add a timestamp and a brief comment on the implementation.
