# Capacitor Mobile: Native Bridging & Storage Standard

Standards for wrapping the React 19 app as a native mobile application.

## 🛠 Native Bridge Tech
- **Core**: Capacitor CLI + Native SDKs (Android SDK/Xcode)
- **Storage**: `@capacitor/sqlite` for mobile (overrides `sql.js` used in web)
- **Security**: `@capacitor/preferences` or Native KeyStore for sensitive session tokens.

## 🎯 Mandatory Patterns
1. **The Build Flow**: 
   - Step 1: `npm run build` (Generate web assets in `dist/`).
   - Step 2: `npx cap sync` (Copy assets to native projects).
   - Step 3: Native Compile (Android Studio/Gradle).
2. **Environment Bridging**: 
   - Android Emulator uses `10.0.2.2` to reach the local backend.
   - Physical devices must use the workstation's `LOCAL_IP` detected via `run-android.sh`.
3. **Database Selection**: Use a conditional driver pattern:
   - Mobile: Use Native SQLite Plugin.
   - Web: Use WASM `sql.js`.
4. **Hardware Lifecycle**: Handle App Pause/Resume events to trigger background sync tasks.

## 📱 UI/UX Standards
- Use **Touch Targets**: Minimum 44x44px for all interactive elements.
- **Viewport Protection**: Use Bootstrap classes to prevent content from hiding behind notches or home indicators.
- **Keyboard Resilience**: Ensure form inputs are visible when the mobile keyboard is active.

## 🚫 Avoid
- Avoid relying on Web-only APIs (like `window.alert`); use Capacitor `Dialog` plugin.
- Avoid hardcoding API URLs; always derive from environment files generated by scripts.
